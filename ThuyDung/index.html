06

Dự án cá nhân

Ba dự án tôi đã thực hiện: bảo mật, thuật toán và cơ sở dữ liệu. Chọn một dự án ở danh sách để xem.

projects/aes-256-file-encryptor

AES-256 File Encryptor

Phát triển ứng dụng mã hóa và giải mã tệp tin bằng Python với AES-256 CBC. Sử dụng PBKDF2 để tạo khóa từ mật khẩu, HMAC-SHA256 để kiểm tra tính toàn vẹn dữ liệu và tích hợp AWS S3 để tải lên, tải xuống, quản lý tệp mã hóa.

  • Python
  • AES-256 CBC
  • PBKDF2
  • HMAC-SHA256
  • AWS S3
  • Bootstrap
projects/sorting-visualizer

Sorting Visualizer

Trực quan hóa các thuật toán Bubble Sort, Quick Sort và Merge Sort bằng Python và Pygame. Mô phỏng quá trình so sánh, hoán đổi phần tử, hỗ trợ sắp xếp tăng dần hoặc giảm dần và giúp người học hiểu rõ nguyên lý hoạt động của từng thuật toán.

  • Python
  • Pygame
  • Bubble Sort
  • Quick Sort
  • Merge Sort
projects/quan-ly-chi-tieu

Hệ thống quản lý chi tiêu cá nhân

Quản lý thu chi cá nhân bằng SQL, theo dõi giao dịch, ngân sách và ví tiền để phân tích biến động chi tiêu, kiểm soát tài chính và thống kê dòng tiền thông qua các truy vấn dữ liệu.

  • SQL
  • Database
  • ERD
  • Data Analysis
  • UI/UX
